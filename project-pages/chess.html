Chess Engine with AI
A fully playable chess game built from scratch in Python, featuring a custom bitboard-based engine and an AI opponent powered by minimax search with alpha-beta pruning.
Background
I came across this project idea online and decided to build it myself. It was important for me to implement the core chess logic from scratch to better understand how board games are structured programmatically. I am not a chess player, so the process was challenging at first. The overall goal was to fully implement the rules of chess and create a simple AI opponent that could beat me.
The application is built using Python and Pygame, with a custom chess engine handling move generation and game state logic. Initially, I used a list-based representation of the board, but due to performance considerations, I later changed it to bitboard-based implementation. I learned that this approach is also used in more advanced chess engines such as Stockfish.
A basic AI opponent was implemented using a minimax algorithm. To improve performance, alpha-beta pruning was added to reduce the number of evaluated positions. The AI evaluates positions using material values and simple piece-square tables. The search depth is limited to 4 plies, which is definetly enough to provide a challenging opponent for me.
The game allows click-to-move interaction through a Pygame-based interface, where the player plays as white against the AI controlling black.
Technologies: Python, Pygame
